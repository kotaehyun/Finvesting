- **vitest 실행 못 함.** VM에서 rollup 네이티브 모듈(맥용)이 안 불러와짐. 맥에서 `pnpm --filter @finvesting/core test`로 `ui-mode.test.ts` 포함 전체를 돌려야 한다
- 전체 `pnpm typecheck`(turbo 8패키지) 못 함. core·web만 직접 tsc
- 라이트 모드, 비즈니스 모바일 화면은 열어 보지 않음
- 비즈니스 모드의 ERP 화면(세금·펀더멘털·재무제표·프로필)은 셸 트리 메뉴와 화면 자체 왼쪽 메뉴가 나란히 보인다. 4단계에서 합칠 것
- 홈이 「불러오는 중…」에서 화면을 캡처해 대시보드 내용은 보지 않음

## 1. 상속세 및 증여세법 제26조
현행: [시행 2026. 1. 2.] [법률 제21065호, 2025. 10. 1., 타법개정]. [조문](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1027435947)

| 구간 | 조문 | 저장 floor~cap / rateBp / addWon | 판정 |
|---|---|---|---|
| 0 | 1억원 이하, 100분의 10 | 0~1억 / 1000 / 0 | ✅ |
| 1 | 1억 초과 5억 이하, 1천만원 + 100분의 20 | 1억~5억 / 2000 / 1천만 | ✅ |
| 2 | 5억 초과 10억 이하, 9천만원 + 100분의 30 | 5억~10억 / 3000 / 9천만 | ✅ |
| 3 | 10억 초과 30억 이하, 2억4천만원 + 100분의 40 | 10억~30억 / 4000 / 2.4억 | ✅ |
| 4 | 30억 초과, 10억4천만원 + 100분의 50 | 30억~ / 5000 / 10.4억 | ✅ |

누진공제 저장값 0 · 1천만 · 6천만 · 1.6억 · 4.6억은 위 식과 같음. 법령 서식의 누진공제 표(0 · 1,000만 · 6,000만 · 16,000만 · 46,000만)와도 같음.

## 2. 지방세법 제111조 제1항 제3호 나목 (그 밖의 주택)
현행: [시행 2026. 7. 1.] [법률 제21308호, 2025. 12. 31., 일부개정]. 제1항 개정 표시는 2019. 12. 31. [조문](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1023670885)

| 구간 | 조문 | 저장 floor~cap / rateBp / addWon | 판정 |
|---|---|---|---|
| 0 | 6천만원 이하, 1,000분의 1 | 0~6천만 / 10 / 0 | ✅ |
| 1 | 6천만 초과 1억5천만 이하, 60,000원 + 1,000분의 1.5 | 6천만~1.5억 / 15 / 6만 | ✅ |
| 2 | 1억5천만 초과 3억 이하, 195,000원 + 1,000분의 2.5 | 1.5억~3억 / 25 / 19.5만 | ✅ |
| 3 | 3억 초과, 570,000원 + 1,000분의 4 | 3억~ / 40 / 57만 | ✅ |

누진공제 0 · 3만 · 18만 · 63만은 위 식과 같음. 1세대 1주택 특례(제111조의2)는 이 표가 아님.

## 3. 종합부동산세법 제9조 제1항
현행: [시행 2026. 1. 1.] [법률 제21224호, 2025. 12. 23., 일부개정]. 제정·개정문은 제9조 세율표를 고치지 않음. [본문](https://www.law.go.kr/LSW/lsInfoR.do?lsiSeq=280417&efYd=20260101&chrClsCd=010202)

2주택 이하·3주택 이상 각 7구간. 저장 floor·cap·rateBp·addWon이 조문 표와 같음. 법인 단일세율(2주택 이하 1천분의 27, 3주택 이상 1천분의 50)은 이 표 밖이며 JSON 주석과 같음.

누진공제는 조문 표에 없고, 저장값은 `구간시작 × 세율 − 가산액`과 같음.

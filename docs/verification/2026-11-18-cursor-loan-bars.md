# 2026-11-18 — Cursor (도면 3D 막대)
- 환경: 맥북. 웹 `http://127.0.0.1:3000/realty`
- 범위: 도면을 키우고, 고른 시도 말잔을 3D 막대로 표시

## 검증됨 (실제 실행)
| 항목 | 방법 | 결과 |
|---|---|---|
| 도면 크기 | 도면 탭에서 `.realty-geo` 크기 | 977×822 |
| 서울 막대 | 목록에서 서울 클릭 후 `.loan-bars` | `rect` 39, `polygon` 78. 카드 710×353. 전년동월 +3.1% |

## 검증 못 함
- 좁은 화면(900px 이하)은 다시 열어보지 않음

# 2026-11-11 — Cursor (로컬 비밀번호 세션)
- 환경: 맥, pnpm 9.15.0, Next.js 15.5.25. 브랜치 `feat/market-terminal-2`
- 범위: `APP_PASSWORD`가 있을 때 쿠키 로그인. 비밀번호는 프로세스 환경변수로만 넣고 `.env`에는 쓰지 않음

## 검증됨 (실제 실행)
| 항목 | 방법 | 결과 |
|---|---|---|
| 세션 단위 테스트 | `vitest run src/session.test.ts` | 4 passed |
| 타입체크 | `pnpm typecheck` | 8패키지 통과 |
| 비밀번호 없음 화면 | 임시 서버 `127.0.0.1:3000`, 쿠키 없음 | 200. 본문에 로그인. 계좌 내비 없음 |
| 틀린 비밀번호 | `POST /api/auth/login` | 401 |
| 맞는 비밀번호 | 같은 경로 후 `/` | 200. 계좌 내비와 로그아웃 있음. 브라우저에서 로그인 화면 → 내비 확인 |
| 쿠키 없는 tRPC | `GET /api/trpc/dashboard.overview` | 401. 메시지 「로그인이 필요합니다.」 |
| 쿠키 있는 tRPC | 같은 경로 | 500. `AggregateError` 연결 실패. Docker가 꺼져 있음 |
| 로그아웃 | 브라우저에서 로그아웃 | 로그인 화면으로 돌아옴 |

## 검증 못 함
- `APP_PASSWORD`가 비어 있을 때의 기존 화면. 이번 서버는 임시 비밀번호를 켜고 확인한 뒤 종료함
- 모바일에서 쿠키 없이 호출
- 호스팅 DB

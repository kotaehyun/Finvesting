# 로드맵

## MVP 1단계 — 자산 현황 + 정보 수집 + 챗봇 (진행 중)
- [x] 스캐폴딩, 스키마, 수집기 뼈대
- [x] 첫 실행 검증
- [x] 계좌·거래 입력 — `/accounts` + 범용 통장 CSV/XLSX (은행별 전용 파서는 샘플 필요)
- [x] 개인 월 차대변 손익 + 고정 세부 + 세액·소비·저축·투자 추이 (`/profile` 프로필대장. 종목 DART/EDGAR 재무제표 화면은 별도)
- [x] 종목 재무제표·감사의견 화면 (`/statements`, DART 숫자+감사의견, 로컬 LLM 읽어주기)
- [x] Yahoo 펀더멘털 표 (`/fundamentals`, 시총·PER·PBR·ROE·배당 일 스냅샷. 재무제표와 별도)
- [x] 보유 종목·체결 입력, 평가손익 표시 (`/holdings`, 최근 종가 연동. 시세 없으면 평단만)
- [x] 재무 프로필 입력 → 배분 가이드 (`/profile` 프로필대장, 월소득 있으면 대시보드·챗에 가이드)
- [x] 보험 증권·보장 공백 레이더 (`/profile` 11 보험내역, 육각·칠각)
- [x] 투자성향 설문·조언 (`/profile` 10, 09 투자내역 다음. 내부 경험 규칙, 종목 추천 없음)
- [x] 거래 분류 수정 (`/accounts`에서 입금=수입, 출금=지출·저축)
- [x] 챗봇에 보유·현금흐름 컨텍스트 추가 (계좌/거래/체결이 있을 때만 주입. 배분 가이드·평가손익은 데이터 있을 때)
- [x] 뉴스 전용 대시보드 (`/news`, 국내·해외·분류·언론 필터)
- [x] 오피니언·칼럼 대시보드 (`/opinions`, 국내 칼럼·애널리스트·해외 오피니언)
- [x] 투자 대시보드 (`/invest`, 세계 지수 Yahoo + TradingView 위젯. Investing.com·Finviz 링크)
- [ ] Financial Timeline (모든 금융 이벤트 시간순) 첫 버전

## 2단계 — Market Terminal
- 관심 종목 심화, KIS 국내/해외 시세, 네이버 뉴스 API, 종목별 뉴스 매핑, RAG

## 3단계 — Tax + Year-End (본인 기준)
- [x] 배당·이자 원장 합, 해외주식 양도 250만원 공제 후 과세대상, 연말정산 공제 칸 (`/profile` 12 개인세무. 세율 없음)
- [ ] 홈택스 간소화 자료 가져오기, 연말정산 제출 자료 XLSX 내보내기

## 4단계 — 서비스화 준비
- [x] 근로자 대장과 사업·프리랜서 업무 화면 분리 (`/erp`. 매출·부가세는 칸. ADR 0034)
- [x] 부가세법 양식·고용보험 시행령 요율·호봉 칸·프리랜서 3.3% 조건 (`/erp`. ADR 0035. 원장·간이 부가가치율·산재 업종요율은 칸)
- [x] 법인사업자 분리 (`/erp` 법인세 양식. 간이과세 없음. 세율 구간 미적용. ADR 0036)
- [x] 차대변 장부·연말정산 공제 창·종소세·비상장 2월 예정신고 (`/erp`·프로필 12. ADR 0037)
- [x] 개인사업자·법인사업자 업무 화면 분리 (`/erp?role=`. 아이콘 격자 없음. ADR 0038)
- [x] 프리랜서 3.3% 직종 한정 (연예인·모델·독립 개발·인플루언서·전문직. 아르바이트에 사업소득 3%를 쓰지 않음. ADR 0039)
- [x] 세무 화면은 법령 문언만 보수적으로 (애매하면 근로소득. 절세 자문 아님. ADR 0040)
- [x] 양도·증여·보유 세율표 (과세표준·누진 설명. 특례는 세무사·국세청. ADR 0041)
- [x] 프리랜서·개인사업자 한 책상 (`/erp` 카드 두 장. 법인만 따로. ADR 0042)
- [x] 분개 전표는 차변·대변 계정과목 (`보통예금` 주석은 은행명. ADR 0043)
- [x] 법인세 별지 제50호·제54호 문언 칸과 직역, 시산 CSV는 빈 칸을 0으로 안 채움 (ADR 0044)
- [x] 면세·확인서·수출입 조문 칸 (제78조 2.10, 부가가치세면세사업자수입금액증명, 제26조 사단·농업, 제21조 영세율, 제50조 수입. ADR 0045)
- [x] 직원등록 다음 건강보험 직장가입자 자격취득 (근로자 명부 제41조, 별지 제6호 제8조 14일. ADR 0046)
- 인증(다중 사용자), 호스팅 DB 이전, worker 컨테이너 배포
- 회계·세무 프로그램 연동: 더존·위하고·세무사랑 전표 양식 내보내기(실제 템플릿 확보 후), 인건비·급여대장·4대보험·원천세 자료, 세무사 전달 패키지

# 로드맵

## MVP 1단계 — 자산 현황 + 정보 수집 + 챗봇 (진행 중)
- [x] 스캐폴딩, 스키마, 수집기 뼈대
- [x] 첫 실행 검증
- [x] 계좌·거래 입력 — `/accounts` + 범용 통장 CSV/XLSX (은행별 전용 파서는 샘플 필요)
- [x] 개인 월 차대변 손익 + 고정 세부 + 세액·소비·저축·투자 추이 (`/profile` 프로필대장. 종목 DART/EDGAR 재무제표 화면은 별도)
- [ ] 종목 재무제표·펀더멘털 화면 (DART/EDGAR/Yahoo 수집분 표시)
- [x] 보유 종목·체결 입력, 평가손익 표시 (`/holdings`, 최근 종가 연동. 시세 없으면 평단만)
- [x] 재무 프로필 입력 → 배분 가이드 (`/profile` 프로필대장, 월소득 있으면 대시보드·챗에 가이드)
- [x] 거래 분류 수정 (`/accounts`에서 입금=수입, 출금=지출·저축)
- [x] 챗봇에 보유·현금흐름 컨텍스트 추가 (계좌/거래/체결이 있을 때만 주입. 배분 가이드·평가손익은 데이터 있을 때)
- [ ] Financial Timeline (모든 금융 이벤트 시간순) 첫 버전

## 2단계 — Market Terminal
- 관심 종목·차트, 경제 캘린더, KIS 국내/해외 시세, 네이버 뉴스 API, 종목별 뉴스 매핑, RAG

## 3단계 — Tax + Year-End (본인 기준)
- 배당·이자소득 집계, 해외주식 양도세 예상(250만원 공제), 연말정산 공제 체크리스트
- 홈택스 간소화 자료 가져오기, 연말정산 제출 자료 XLSX 내보내기

## 4단계 — 서비스화 준비
- 인증(다중 사용자), 호스팅 DB 이전, worker 컨테이너 배포, Accounting/Labor 모듈(프리랜서·사업자)
- 회계·세무 프로그램 연동: 더존·위하고·세무사랑 전표 양식 내보내기(실제 템플릿 확보 후), 인건비·급여대장·4대보험·원천세 자료, 세무사 전달 패키지

## 5단계 — AI 고도화
- 이상 지출 탐지, 리스크 설명, 반복 실수 패턴, 능동 알림, DGX Spark/vLLM 프로바이더

# logs — 실행 로그 · 오류 기록

오류를 만나면 아래 형식으로 파일 하나씩 추가한다: `YYYY-MM-DD-짧은제목.md`
같은 오류를 두 번 겪지 않는 것이 목적. AI 도구는 오류를 만나면 **먼저 이 폴더를 검색**한다.

## 형식
```
# 제목
- 날짜:
- 환경: 맥북 / 윈도우, Node·pnpm 버전
- 어디서: 명령어 또는 화면
- 증상: 오류 메시지 원문
- 원인:
- 해결: 실제로 효과 있었던 조치
- 재발 방지: (있으면)
```

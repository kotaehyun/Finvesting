# UI 규칙

웹(`apps/web`) 화면 공통. 새 화면·고칠 때 이 문서를 따른다.

## 색 (시세·손익)
- CSS 변수만 쓴다: `--tone-up`(오름·플러스), `--tone-down`(내림·마이너스), `--tone-flat`(0), `--tone-warn`(경고 강조).
- 클래스는 `.up` / `.down` / `.flat` / `.warn`. tsx에 `#dc2626` 같은 색을 직접 쓰지 않는다. 캔버스·지도는 `@/lib/tones`의 `toneColors()`.
- 가격·평가손익·지수: 빨강 오름 / 파랑 내림(국내 증권 관례).
- 0은 중립(flat). 화살표 없음, 「변동 없음」 등.
- `-0원` 금지. 부호 있는 금액은 core `signedWon`·`pnlTone`.

## 다크·라이트
- ERP(`.erp`)는 `--erp-*` 변수만 쓴다. `.erp.wehago`도 라이트·다크에서 변수 값만 바꾼다. 다크에서 흰 바탕·어두운 라벨을 다시 박지 않는다.
- 라벨 칸(`th`)은 `--erp-label`. 다크에서 머리 배경 대비 4.5:1 이상.
- 새 화면은 라이트·다크를 열어 보고 검증 기록에 남긴다.

## 계정 모드 (ADR 0067)
- 일반(`personal`) = 카드형, 비즈니스(`business`) = ERP형. 데이터·계산은 같고 셸·메뉴·말투만 다르다.
- 모드는 쿠키 `finvesting_ui_mode`. 머리말 오른쪽 「일반 / 비즈니스」 스위치로 바꾼다. 바꾸면 홈으로 간다.
- 메뉴 정의는 `packages/core/src/ui-mode.ts` 하나뿐이다. 새 화면을 만들면 **두 모드 메뉴 중 적어도 한 곳**에 넣는다(테스트가 확인).

| 일반 (위쪽) | 하위 화면 |
|---|---|
| 홈 | `/` |
| 거래 흐름 | 거래 흐름, 계좌·거래 |
| 투자 | 투자 대시보드, 내 보유, 시장, 재무제표, 기업 숫자, 뉴스, 오피니언 |
| 집 | 부동산 |
| 세금 | 세금·연말정산, 급여·공제 입력 |
| AI 비서 | 챗 |

| 비즈니스 (왼쪽 트리) | 하위 화면 |
|---|---|
| 대시보드 | 이번 달 현황 |
| 장부 | 계좌·거래, 회계전표·내보내기, 거래 흐름 |
| 세무 | 양도세·금융소득·연말정산, 업무 책상(보기), 부가세·원천세 신고(준비 중, ADR 0050) |
| 급여·인사 | 근로자 대장, 급여 대장·4대보험(준비 중) |
| 투자·기업 | 보유·체결, 재무제표, 기업 숫자 |
| 시장 | 투자 대시보드, 시장, 부동산, 뉴스, 오피니언 |
| AI | AI 비서 |

- 메뉴는 `next/link`, 지금 화면은 `aria-current="page"`로 강조한다.
- 같은 기능을 모드마다 두 번 만들지 않는다. 화면이 모드마다 달라야 하면 페이지에서 모드를 보고 컴포넌트만 고른다.

## 모드별 화면 (3·4단계)
- 일반: `/tax`·`/holdings`·`/accounts`·`/fundamentals`·`/statements`·`/profile`는 카드형(`card-page`). 왼쪽 ERP 메뉴 대신 위쪽 탭·종목 칩. 전표·업무 링크 숨김.
- 비즈니스: 셸 왼쪽 트리가 앱 메뉴. 화면 안 `.erp-menu`(근로자 대장 칸, 업무 책상 칸)는 숨기지 않고 가로 탭 줄로 둔다. 홈 제목 「이번 달 현황」, 타임라인 제목은 일반·비즈니스 모두 「거래 흐름」.
- 화면을 바꾼 브랜치는 일반·비즈니스 × 라이트·다크로 열어 본 검증 기록이 있어야 `dev`에 머지한다.
- `/tax` 구분(해외주식·배당·이자·연말정산)은 한 줄 버튼이다. 비즈니스에서 본문 그리드가 남는 높이를 나눠도 이 버튼은 세로로 늘어나지 않는다.
- `/accounting` 회계전표는 기간(연·월)과 내보내기(더존·위하고·세무사랑·엑셀)를 툴바에서 나눈다. 돈 종류는 본문 칩이다. 왼쪽 `.erp-menu`에 두면 비즈니스 셸이 가린다. 전표는 한 장당 한 줄이고, 고르면 옆에 들어옴·나감이 나온다. 본문에 `fund-triangle-layout` 흰 칸을 쓰지 않는다. 파일은 고른 월의 전부이고, 종류 칩은 화면만 거른다.
- `/fundamentals` 기업 숫자는 검색·AI·조회 링크만 툴바에 둔다. 시장·자산·그림/표는 본문 칩이고, 종목 목록은 본문 왼쪽이다. `.erp-menu`에 두면 비즈니스 셸이 가린다. 그림과 고른 종목은 나란히 두고, 삼각 SVG·상세 칸은 `--erp-*`(일반 모드는 카드 변수)만 쓴다. 흰 바탕 레이아웃을 쓰지 않는다.
- `/statements` 재무제표는 검색만 툴바에 둔다. 국내·해외, 시장·보기·섹터·공시는 본문 왼쪽 목록이다. `.erp-menu`에 두면 비즈니스 셸이 가린다. 수집 표와 기업 요약은 나란히 두고, 요약 칸은 `--erp-*`만 쓴다.
- `/accounts` 거래 내역은 통장 앱(토스·카카오뱅크·시중은행)과 같이 계좌 카드, 기간·입출금 필터, 날짜별 목록이다. 입금은 `--accent`(파랑, `+`), 출금은 본문색(`-`), 이체는 흐린색, 0은 flat. 시세의 `.up`/`.down`(빨강 오름)을 입출금에 쓰지 않는다. 합계는 불러온 거래만 더하고, 한도에 걸리면 그 사실을 적는다.
- 페이지에서 모드는 `useUiMode()` (`UiModeProvider`가 레이아웃에서 주입).

## 스타일 파일 (ADR 0067 5단계)
`apps/web/src/app/globals.css`는 진입점이다. 규칙은 `apps/web/src/styles/`에 있다.

| 파일 | 내용 |
|---|---|
| `tokens.css` | 색·글꼴 변수, 공통 뼈대, `.up` `.down` `.flat` `.warn` |
| `chat.css` | 투자 봇 대화 |
| `erp.css` | 재무제표, 기업 숫자, 프로필대장, 세금·연말정산 |
| `card.css` | 뉴스·시장·부동산·타임라인·순자산·계좌 거래 |
| `app/shell.css` | 계정 모드 셸 (일반 카드형 보정 포함) |

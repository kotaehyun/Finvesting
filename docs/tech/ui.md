# UI 규칙

웹(`apps/web`) 화면 공통. 새 화면·고칠 때 이 문서를 따른다.

## 색 (시세·손익)
- CSS 변수만 쓴다: `--tone-up`(오름·플러스), `--tone-down`(내림·마이너스), `--tone-flat`(0), `--tone-warn`(경고 강조).
- 클래스는 `.up` / `.down` / `.flat` / `.warn`. tsx에 `#dc2626` 같은 색을 직접 쓰지 않는다. 캔버스·지도는 `@/lib/tones`의 `toneColors()`.
- 가격·평가손익·지수: 빨강 오름 / 파랑 내림(국내 증권 관례).
- 0은 중립(flat). 화살표 없음, 「변동 없음」 등.
- `-0원` 금지. 부호 있는 금액은 core `signedWon`·`pnlTone`.

## 다크·라이트
- ERP(`.erp`)는 `--erp-*` 변수만 쓴다. `.erp.wehago`도 라이트·다크에서 변수 값만 바꾼다. 다크에서 흰 바탕·어두운 라벨을 다시 박지 않는다.
- 라벨 칸(`th`)은 `--erp-label`. 다크에서 머리 배경 대비 4.5:1 이상.
- 새 화면은 라이트·다크를 열어 보고 검증 기록에 남긴다.

## 계정 모드 (ADR 0067)
- 일반(`personal`) = 카드형, 비즈니스(`business`) = ERP형. 데이터·계산은 같고 셸·메뉴·말투만 다르다.
- 모드는 쿠키 `finvesting_ui_mode`. 머리말 오른쪽 「일반 / 비즈니스」 스위치로 바꾼다. 바꾸면 홈으로 간다.
- 메뉴 정의는 `packages/core/src/ui-mode.ts` 하나뿐이다. 새 화면을 만들면 **두 모드 메뉴 중 적어도 한 곳**에 넣는다(테스트가 확인).

| 일반 (위쪽) | 하위 화면 |
|---|---|
| 홈 | `/` |
| 돈의 흐름 | 타임라인, 계좌·거래 |
| 투자 | 투자 대시보드, 내 보유, 시장, 재무제표, 기업 숫자, 뉴스, 오피니언 |
| 집 | 부동산 |
| 세금 | 세금·연말정산, 급여·공제 입력 |
| AI 비서 | 챗 |

| 비즈니스 (왼쪽 트리) | 하위 화면 |
|---|---|
| 대시보드 | 이번 달 현황 |
| 장부 | 계좌·거래, 회계전표·내보내기, 거래 흐름 |
| 세무 | 양도세·금융소득·연말정산, 업무 책상(보기), 부가세·원천세 신고(준비 중, ADR 0050) |
| 급여·인사 | 근로자 대장, 급여 대장·4대보험(준비 중) |
| 투자·기업 | 보유·체결, 재무제표, 기업 숫자 |
| 시장 | 투자 대시보드, 시장, 부동산, 뉴스, 오피니언 |
| AI | AI 비서 |

- 메뉴는 `next/link`, 지금 화면은 `aria-current="page"`로 강조한다.
- 같은 기능을 모드마다 두 번 만들지 않는다. 화면이 모드마다 달라야 하면 페이지에서 모드를 보고 컴포넌트만 고른다.

## 모드별 화면 (3·4단계)
- 일반: `/tax`·`/holdings`·`/accounts`·`/fundamentals`·`/statements`·`/profile`는 카드형(`card-page`). 왼쪽 ERP 메뉴 대신 위쪽 탭·종목 칩. 전표·업무 링크 숨김.
- 비즈니스: 셸 왼쪽 트리가 메뉴. `.bshell .erp-menu`는 숨긴다(이중 메뉴 방지). 홈 제목 「이번 달 현황」, 타임라인 「거래 흐름」.
- 페이지에서 모드는 `useUiMode()` (`UiModeProvider`가 레이아웃에서 주입).

## 범위 밖 (다음 단계)

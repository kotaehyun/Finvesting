# 세금 & 연말정산 모듈 (`tax`)

## 개요
개인 투자자 및 근로소득자를 위한 3대 핵심 세무 터미널 모듈입니다.
1. **해외주식 양도소득세 및 Tax-Loss Harvesting 절세 시뮬레이터**
2. **배당·이자 금융소득 종합과세(연 2,000만원) 한도 모니터링**
3. **근로소득 연말정산 인터랙티브 시뮬레이터 & 공제 체크리스트 (13월의 월급 환급액 예측)**

---

## 1. 해외주식 양도소득세 (`packages/core/src/tax.ts`)
- **과세 대상**: 미국 등 해외 주식/ETF의 매도 체결 건 (국내 KRX 제외, 통화 USD 등).
- **손익통산**: 1월 1일 ~ 12월 31일 연간 매도 체결의 실현손익을 합산.
- **기본공제**: 연 2,500,000원 (`OVERSEAS_CAPITAL_GAINS_BASIC_DEDUCTION`).
- **세율**: 22% (양도소득세 국세 20% + 지방소득세 2%).
- **Tax-Loss Harvesting (손실 통산 절세)**:
  - 연간 실현이익이 기본공제 250만원을 초과했을 때, 보유 중인 마이너스 평가손익 해외 종목을 연말 전 매도하여 세금을 절감하도록 계산.
  - 절세 가능액 = `min(초과이익, 보유손실합) × 22%`.

---

## 2. 금융소득 종합과세 모니터링
- **수집 대상**: `investment_incomes` 테이블 (배당금, 이자소득).
- **기준선**: 연 20,000,000원 (`FINANCIAL_INCOME_TAX_THRESHOLD`).
- **세율**:
  - 2천만원 이하: 원천징수 15.4% (소득세 14% + 지방세 1.4%) 분리과세 종결.
  - 2천만원 초과: 초과분이 근로/사업 등 종합소득과 합산되어 기본 누진세율(6%~45%) 적용, 피부양자 자격 박탈 위험.
- **상태 구분**:
  - `safe` (< 75%): 안전 구간
  - `caution` (75% ~ 100%): 주의 구간
  - `exceeded` (>= 100%): 종합과세 대상 초과

---

## 3. 근로소득 연말정산 시뮬레이터
- **연동 데이터**: 급여대장(`payroll_months`), 재무프로필(`financial_profiles`), 보험(`insurance_policies`), 저축(`savings_contributions`).
- **계산 파이프라인**:
  1. 총급여(Gross Salary) → 근로소득공제 (소득세법 제47조) → 근로소득금액.
  2. 소득공제:
     - 기본 인적공제 (본인 150만원 + 부양가족 1인당 150만원)
     - 4대보험 공제 (국민연금 100% + 건보/고용 100%)
     - 주택청약종합저축 (연 납입액 최대 300만원 한도의 40%, 총급여 7천만원 이하)
     - 신용카드/체크카드 (총급여 25% 초과분에 대해 신용 15%, 체크/현금 30%)
  3. 과세표준 = Max(0, 근로소득금액 - 소득공제 합계).
  4. 산출세액 = 종합소득 기본 누진세율 (6% ~ 45%) × 1.1 (지방소득세 포함).
  5. 세액공제:
     - 근로소득 세액공제 (산출세액 기준 한도 적용)
     - 연금계좌 세액공제 (연금저축 최대 600만, IRP 합산 최대 900만; 총급여 5,500만 이하 16.5%, 초과 13.2%)
     - 보장성 보험료 세액공제 (연 최대 100만원 한도의 13.2%)
  6. 결정세액 = Max(0, 산출세액 - 세액공제 합계).
  7. 차감징수세액 = 기납부세액 - 결정세액 (양수 = 13월의 월급 환급, 음수 = 추가 납부).

## 4. API 엔드포인트 (`packages/api/src/routers/tax.ts`)
| 프로시저 | 형태 | 설명 |
|---|---|---|
| `tax.summary` | Query | 연도별 3대 세목 종합 요약 및 KPI 지표 반환 |
| `tax.capitalGains` | Query | 해외주식 실현 매도 체결 및 Tax-loss harvesting 상세 |
| `tax.financialIncome` | Query | 배당·이자 수취 내역, 월별 흐름, 2천만원 게이지 |
| `tax.simulateYearEnd` | Query | 10대 공제 변수 조절 시 즉시 재계산 시뮬레이션 |
| `tax.addIncome` | Mutation | 신규 배당/이자 수취 내역 등록 (원천징수 15.4% 자동 계산) |
| `tax.parseHometaxUpload` | Mutation | 국세청 홈택스 간소화 파일(JSON 또는 요약 CSV) 파싱 및 공제액 추출 |
| `tax.exportXlsx` | Query | 회사/세무대리인 제출용 4개 시트 통합 정산서 XLSX 엑셀 생성 |

## 5. 홈택스 간소화 파서 및 XLSX 엑셀 내보내기 (`packages/interop`)
- **홈택스 파서 (`importers/hometax.ts`)**:
  - 홈택스 연말정산 간소화 전자문서 표준 JSON(서식코드 P101, P102, J301, A102, G107, G207, G307 등) 및 CSV 파일 자동 인식.
  - 연금저축, IRP, 청약, 보장성보험, 신용/체크카드 지출액을 추출하여 시뮬레이터에 일괄 자동 주입.
- **연말정산 XLSX 생성기 (`exporters/tax-settlement-xlsx.ts`)**:
  - `SheetJS` 기반 4개 시트 워크북 생성:
    1. `연말정산_정산요약`: 총급여, 근로소득공제, 과세표준, 산출세액, 세액공제, 최종 결정세액, 기납부세액, 차감징수세액(환급액).
    2. `공제_세부명세`: 소득공제 및 세액공제 항목별 지출액, 법정한도, 공제율, 반영액.
    3. `해외주식_양도소득세`: 매도가액, 취득가액, 제비용, 250만 공제, 과세표준, 22% 세액, 매도 체결 목록.
    4. `금융소득_배당이자`: 연간 세전 배당/이자, 원천징수 15.4%, 실수령액, 2천만 한도 게이지, 수취 상세 내역.

---

## 6. 프론트엔드 화면 (`apps/web/src/app/tax/page.tsx`)
- URL: `/tax`
- 상단 3대 바롬메터 KPI 카드 (해외주식 세액, 금융소득 한도 소진율 게이지, 연말정산 환급/추가납부액)
- 상단 헤더 액션 컨트롤:
  - `📥 연말정산 XLSX 내보내기`: 원클릭으로 엑셀 파일 다운로드
  - `📂 홈택스 간소화 불러오기`: 모달 드롭존에서 파일 업로드 즉시 공제 필드 반영 및 환급액 자동 갱신
- 3개 탭 뷰 (해외주식, 금융소득, 연말정산)
- 실시간 인풋 슬라이더/필드 변경 시 즉시 재계산 및 시각적 반응

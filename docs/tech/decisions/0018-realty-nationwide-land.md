# 0018. 부동산 도면은 전국 + 토지 칸

- 상태: 채택
- 날짜: 2026-09-15

## 배경
도면·가계대출 순위가 서울·경기·인천만 보였다. 매물 칸에 토지가 없었다.

## 결정
- 도면 GeoJSON은 통계청 2018 **전국** 시군구(`korea-plan.json`). 멀리서는 17개 시도 이름, 확대하면 시·구. 규제·정비권역 색은 수도권만. 동탄구 면은 여전히 없음.
- 예금은행 가계대출은 ECOS `151Y003` **광역시도 전체** 이름 매칭(서울…제주). 항목코드 추측 금지. 시·구 숫자는 없음.
- 유형 칸에 **토지**를 추가. 포털 매물 호수는 안 긁음. 키 후 국토부 토지 실거래 건수.

## 결과
웹 `/realty`가 전국 면 + 17개 시도 순위. 토지 빈 그래프. 숫자는 ECOS·data.go.kr 키가 있을 때만.

# 0020. 부동산 고가주택 방향은 국세 집계

- 상태: 채택
- 날짜: 2026-09-15

## 배경
자산이 많은 사람의 부동산 이동을 보고 싶다는 요청이 있다. 홈택스 개인 납부액·자산 조회와 실명 명단은 세법상 비밀이다. 고위공직자 재산공개는 1,903명뿐이고 종부세 주택분(54만)에서 뺄 수 없다.

## 결정
- 개인 세금 조회·스크래핑 없음. 기재부 종부세 고지(2025-11-26)와 국세청 TASIS·data.go.kr 표만 쓴다.
- `/realty`에 고가주택 세금 방향 섹션을 공직자 표와 분리한다. 숫자는 과세기준일 주택 **소재** 인원이지 전입이 아니다. 공시가 상승(+3.65%)도 인원을 늘린다.
- 기재부가 밝힌 수도권 3곳(서울·인천·경기)만 인원 칸. 17개 시도 양도세·고가주택 양도는 TASIS 링크와 빈 칸.
- 지역 절대 인원은 연합뉴스가 기재부 참고 2를 인용한 숫자. KDI 요약에는 증가율만 있다.

## 결과
`core/realty-nts.ts` + `/realty` 패널. 홈택스 API 없음.

# 0059 — 챗 대화는 세션 테이블에 남긴다
- 상태: 채택 (2026-11-12)
- 배경: 스트리밍 다음 칸은 `chat_sessions` · `chat_messages`다. 화면은 탭을 닫으면 대화가 사라졌다.
- 결정: 사용자 질문과 봇 답만 저장한다. 시스템 프롬프트와 뉴스 본문은 넣지 않는다. 제목은 첫 질문의 앞 40자. 한 대화는 메시지 40개까지. 새 대화는 저장분을 지우지 않고 빈 화면으로 돌아간다. 빈 화면에서 최근 20개를 다시 연다.
- 결과: 멈추거나 답이 비면 질문만 남는다. 답 도중이면 그때까지 온 글을 남긴다.

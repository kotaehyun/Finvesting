# 0057 — 네이버 뉴스 검색은 보유·관심과 저장된 KRX 한글 이름
- 상태: 채택 (2026-11-11). ADR 0051을 대체한다.
- 배경: 사용자가 NAVER API HUB 키를 받았다. 0051은 종량제라 호출하지 않기로 한 결정이다. 공식 문서(2026-09-17)의 뉴스 검색은 `GET https://naverapihub.apigw.ntruss.com/search/v1/news`이고, 헤더는 `X-NCP-APIGW-API-KEY-ID`·`X-NCP-APIGW-API-KEY`다. 검색 API 하루 호출 한도는 25,000회다. 단가 표는 확인하지 않았다.
- 결정: 키가 있으면 호출한다. 환경변수는 `NAVER_CLIENT_ID`·`NAVER_CLIENT_SECRET`이다. 없으면 skip. 검색어는 보유·관심의 한글 이름과, 이미 저장된 KRX 종목의 한글 이름이다. 같은 이름은 한 번. 지수·원자재의 짧은 한글 이름(은·구리·브렌트)은 검색하지 않는다. 한 번에 최대 40개이고 서울 날짜로 페이지를 돌린다. `display=10`, `sort=date`, `start=1`. 하루 4회(08·12·16·20시). 저장은 제목·원문 링크·요약 500자·호스트 이름. 본문과 응답 원문은 저장하지 않는다. `symbols`는 제목 규칙으로만 채운다 (ADR 0052). 출처 `naver:news`는 국내 금융. 2026-11-12: 보유·관심에 한글 이름이 없어도 저장된 KRX 이름을 검색한다.
- 결과: 예전 개발자센터 `openapi.naver.com`은 호출하지 않는다. 네이버 증권 링크는 이 API가 아니다.

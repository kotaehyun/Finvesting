# 0048. 투자 봇AI 화면은 대화형 채팅 배치

- 상태: 채택
- 날짜: 2026-09-21

## 배경
`/chat`은 제목·스타터 칩·카드 말풍선·한 줄 입력이 위에서 아래로 쌓여 질의 창이라기보다 목록 페이지에 가깝다. 사용자는 ChatGPT처럼 가운데 인사와 아래 입력칸을 원한다.

## 결정
- 화면 이름은 **투자 봇AI**. ChatGPT가 아니다.
- 색은 자산 홈 파랑과 다르게 한다. 배경은 따뜻한 종이색, 강조·보내기는 청록(`--chat-accent` / `--chat-send`). 사용자 말풍선은 연한 청록. 다크도 같은 계열.
- `/chat`은 빈 화면 인사(「무엇을 도와드릴까요?」)·제안 카드·아래 고정 입력칸. 메시지가 있으면 사용자 말풍선은 오른쪽, 봇 답은 왼쪽 마크다운.
- Enter 전송, Shift+Enter 줄바꿈. 한글 IME는 `isComposing`을 본다 (`docs/logs/2026-09-02-chat-ime-enter.md`).
- 제안 카드는 `starters.ts` 그대로. 처음엔 그룹당 1개, 「다른 질문」으로 나머지. 대화가 시작되면 제안은 접는다.
- ChatGPT 로고·이름·복제 UI 키트를 쓰지 않는다. OpenAI API를 붙이지 않는다. 답은 로컬 Ollama.
- 대화 기록 테이블은 아직 없다. 「새 대화」는 이 탭 상태만 비운다. 저장·스트리밍은 `docs/tech/ai.md` 계획.

## 결과
`apps/web/src/app/chat/page.tsx`, `.chat-shell`. 내비 라벨은 투자 봇AI.

# 0064 — 반복 패턴은 손실 매도 뒤 재매수 횟수만 센다

- 상태: 채택 (2026-11-22)
- 배경: 5단계의 「반복 실수 패턴」에 계산 규칙이 없었다. 실수라는 가치 판단을 숫자로 만들면 출처가 없다.

## 결정
1. 체결(`trades`)만 본다. 계좌×종목마다 보유 재생과 같은 순서로 재생한다. 계좌를 섞지 않는다.
2. 매도 한 건의 원화 실현손익이 0보다 작으면, 그 직후 같은 계좌·같은 종목의 다음 매수 1건을 센다. 이익 매도·손익 0은 빼 둔다.
3. 같은 패턴이 2회 미만이면 목록에 넣지 않는다. 1회는 반복이 아니다.
4. 화면·챗에는 「손실 실현 뒤 같은 종목을 다시 산 횟수」라고만 적는다. 실수라고 단정하지 않는다.
5. 시세·변동폭·인구 통계를 쓰지 않는다. 결과는 저장하지 않고 조회할 때 계산한다.

## 결과
`packages/core/src/repeat-mistake.ts`. 홈 `/` 「반복 패턴」. 챗은 `반복 패턴` 블록.

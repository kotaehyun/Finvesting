# 0023. 부동산 공실 정의·상환·경매·임대업은 공개 집계만

- 상태: 채택
- 날짜: 2026-09-15

## 배경
공실을 법인이 자가로 낮춘다는 말, 급매·유찰, 영끌, 상권 소비, 꼬마·중형 빌딩 부채를 한 화면에 넣고 싶다는 요청이 있다. 포털 급매·민간 경매 유찰률·상권정보시스템 매출은 공식 시계열이 아니거나 긁으면 안 된다.

## 결정
- 부동산원 공실은 **임대계약 없음 + 자가·무상임대 아님**. 법인이 자가로 쓰면 공실이 아니다. 채운 면적 자체는 공표가 없어 칸.
- 주택 빈집은 총조사 유형별(아파트 7.1%가 가장 낮음). 사람이 살면 법인 보유여도 빈집이 아니다.
- 상환: 한은 금안보 가계·주담대·기타·자영업 연체. 영끌은 고위험가구(DSR>40%·DTA>100%) 청년 비중.
- 경매: 대법원 신청 건수·HUG 비중. 매각·유찰 월별은 법원 원문 칸.
- 꼬마·중형 빌딩: 전용 시계열 없음. 기업 부동산업 연체·잔액 비중 + 금융위 비주택 RTI 1.5배 + 부동산원 상가 투자수익률.
- 상권 소비액은 소상공인365 링크. 스크래핑 없음.

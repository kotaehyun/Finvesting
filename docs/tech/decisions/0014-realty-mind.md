# 0014. 부동산 지역은 마인드맵 + 공식 고시 요약

- 상태: 채택
- 날짜: 2026-09-15

## 배경
`/realty` 상단 3칸(과밀·성장·자연 칩)만으로는 규제지역과 고대출 위험이 한눈에 안 들어온다.

## 결정
- UI는 중앙 「수도권」에서 정비권역·규제지역·고대출 위험군으로 갈라지는 **마인드맵**.
- **정비권역**은 수도권정비계획법 시행령 별표1 요약(ADR 0011과 같음).
- **규제지역** 시·구는 스크래핑하지 않는다. 정책브리핑 10.15(서울 25구·경기 12곳, 효력 2025-10-16)와 2026-06-30(화성 동탄구·용인 기흥구·구리시, 효력 2026-07-01)만 적는다. 수원 권선·화성 전체·용인 처인은 넣지 않는다.
- **고대출 위험군**은 금융위 「대출수요 관리 방안」 요약: LTV 40%, 구입 한도 6·4·2억, 스트레스 DSR 3%, 다주택, 전세·신용 제한, 토허 비주택 40%. 개인 한도 계산기가 아니다.
- 지정은 고시로 바뀐다. 청약홈·국토부·금융위 원문 링크를 같이 둔다. 매수 권유가 아니다.
- 지도 타일·점은 ADR 0015 → **시군구 도면**(ADR 0015).

## 결과
`core/realty-ref.ts`, 웹 `/realty`. 실거래 숫자는 키 발급 후.

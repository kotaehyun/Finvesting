# 0016. 부동산 도면은 3D + 시도 가계대출 그래프

- 상태: 채택
- 날짜: 2026-09-15

## 배경
2D 시군구 면만으로는 지역을 골랐을 때 대출 총액·증가율이 안 보인다. CSS `rotateX`는 클릭 좌표가 어긋난다. 시·구 가계대출 공식 시계열은 없다.

## 결정
- 도면은 **MapLibre GL `fill-extrusion`**(pitch/bearing). 타일 없음. 색은 ADR 0014·0015.
- 기둥 높이는 **예금은행 광역시도 말잔 비율**(서울 구는 같은 높이). 시·구 대출액처럼 보이지 않는다.
- 시계열은 ECOS `151Y003` 가계대출(계정 `1111000`, 주택 `11110A0`). 지역 항목코드는 `StatisticItemList`에서 이름(서울·경기·인천·전국) 매칭. 코드 추측 금지.
- 증가율은 `core`에서 전년동월·전월. 단위 십억원 → 조원.
- 연체율 `141Y005`는 지역 항목이 목록에 있을 때만.

## 결과
웹 `/realty`에서 시·구 이름이 면에 붙고, 고르면 그 시도 총액·증가율 그래프. worker `collectEcos`가 시계열을 넣음. Next에서 GeoJSON이 안 올라오면 `public/maplibre-gl-worker.mjs`(+ shared)로 워커 URL을 고정한다.

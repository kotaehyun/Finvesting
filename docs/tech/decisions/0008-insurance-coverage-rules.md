# 0008 — 보험 보장 권장액은 연소득 경험 규칙
- 상태: 채택 (2026-09-13)
- 배경: 프로필대장에 가입 보험과 부족한 보장을 육각·칠각 레이더로 보려 한다. 공식 고시(금융감독원 권고액 등)는 개인 소득·부양·기존 공적보장에 따라 달라 이 앱에 고정할 수 없다.
- 결정:
  - 민영 증권만 `insurance_policies`에 적는다. 4대보험(급여 공제)과 분리.
  - 칠각 축: 사망·실손·암·뇌혈관·심장·상해·후유장해. 육각은 뇌+심장을 **중대질병**으로 합친다.
  - 권장액(연소득 `Y` = 세전 월소득×12): 사망 `5Y`, 실손 가입(1/0), 암 `max(5천만, Y)`, 뇌·심장 각 `max(5천만, 0.8Y)`, 상해 `max(3천만, 0.5Y)`, 후유장해 `3Y`.
  - 점수 = `min(1, 가입합/권장)`. 계산은 `packages/core/src/insurance-coverage.ts`.
- 결과: 그래프는 “어디가 0에 가까운지”를 보여 주는 가이드다. AI 추천(`insurance.recommend`)은 같은 숫자를 우선순위로 설명할 뿐, 설계사 견적·특정 상품 추천이 아니다.

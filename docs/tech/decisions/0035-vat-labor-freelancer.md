# 0035. 부가세·고용보험·프리랜서 3.3%는 법령 양식

- 상태: 채택
- 날짜: 2026-09-18

## 배경
부가세 10%, 직원 고용보험, 프리랜서 3.3%를 같은 세금으로 보는 사람이 많다. 0034는 원장 없이 세율을 추정하지 말라고 했다. 법령에 적힌 요율 양식은 그와 별개다.

## 결정
- `/erp?view=vat` 부가가치세법 제30조 10% 골격. 일반/간이/면세 구분. 예정·확정 달력. 간이 업종 부가가치율·홈택스 XML은 칸.
- `/erp?view=labor` 고용산재보험료징수법 시행령 제12조 요율표. 호봉은 ADR 0047(별표 3). 산재 업종요율은 복사하지 않음. 2026 최저임금 월 2,156,880원.
- `/erp?view=withholding`·용역수입: 소득세법 제129조 제1항 제3호 3% + 지방세 그 10%. 이 화면은 연예인·모델·독립 개발·인플루언서·전문직만(ADR 0039). 개원 전문직은 개인사업자. 아르바이트에 사업소득 3%를 쓰지 않음(제20조·제129조 제1항 제1호. ADR 0040).
- 화면 숫자는 사용자가 넣은 시산만. 원장에 곱해 신고 확정액을 저장하지 않음. 더존·위하고 업로드 양식 아님.
- 0034 「세율 추정 없음」은 빈 원장에 세액을 만들지 말라는 뜻. 위 법령 요율 양식은 예외.
- 후속: 면세·2월 현황신고·수출입은 ADR 0045. 직원등록·건강보험 자격취득은 ADR 0046.

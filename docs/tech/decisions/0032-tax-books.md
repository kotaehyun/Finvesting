# 0032. 본인 세무 미리보기는 공제·원장만, 세율은 없음

- 상태: 채택
- 날짜: 2026-09-18

## 배경
로드맵 3단계는 배당·이자 집계, 해외주식 양도 250만원 공제, 연말정산 공제 체크리스트다. 홈택스 간소화 파일과 더존·위하고 빈 템플릿은 없다. 04 세액은 월 근로소득세 입력이다.

## 결정
- 프로필 12 `세무·회계`. 해외주식 양도는 평단법 원화 실현손익 − 연 250만원(로드맵). 원장에 결정세액을 쓰지 않음. 법령 세율표는 ADR 0041.
- 배당·이자는 `investment_incomes` 수집분만. 입력 UI·세율 추정 없음.
- 공제 칸: 근로소득공제·본인 150만은 해당 연 `payroll_months`가 있을 때만. 07 추이처럼 프로필 현재월로 빈 달을 채우지 않음. 의료비·카드·부양가족은 칸.
- 장부는 기존 범용 CSV. 더존·위하고는 실제 양식 파일 후에.

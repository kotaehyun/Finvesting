# 0015. 부동산은 시군구 도면 + 공식 고시 색

- 상태: 채택
- 날짜: 2026-09-15

## 배경
OSM 거리 지도 + 점은 도면이 아니다. 시·구가 어디에 붙는지 면으로 보여야 한다.

## 결정
- **타일 없음.** Leaflet에 통계청 2018 시군구 경계(southkorea-maps topo-simple → 수도권만 단순화)를 칠한다.
- 색은 ADR 0014와 같음. 수원 권선·용인 처인·안양 만안은 규제 면이 아니다.
- **동탄구 면은 2018 원본에 없다.** 화성시는 성장관리 면 + 동탄 중심 점선 원.
- 카카오·네이버·CARTO 키 없음. 필지 경계는 토지이음.

## 결과
웹 `/realty` 수도권 도면. 면·칩을 누르면 그 시·구로 확대. 렌더러는 ADR 0016에서 MapLibre 3D로 바꿈.

# 0068 — 은행 계좌 API는 문서만 두고 아직 호출하지 않음

- 상태: 채택 (2026-11-26). 구현은 보류. 사용자 「아직은 넣지마」.
- 배경: `/accounts`는 은행에서 받은 CSV·엑셀·워드를 올려 `transactions`에 넣는다 (`docs/tech/interop.md`). 한은 ECOS·FRED처럼 개인 키만으로 내 통장 입출금을 받는 공개 API는 이 저장소에 없다. 국내에서 제3자 앱이 본인 계좌를 읽으려면 금융결제원 오픈뱅킹(이용기관)이나 마이데이터(본인신용정보관리업)를 통해야 하고, 개인 로컬 앱에 그 자격이 없다. 카카오뱅크·토스·국민·신한 앱이 개인에게 거래내역 API를 열어 두었다는 기록도 없다.

## 결정

1. 오픈뱅킹·마이데이터 클라이언트, 환경변수 키, `/accounts` 연동 버튼, 워커 수집은 **만들지 않는다.**
2. 인터넷뱅킹 아이디·비밀번호를 저장하거나 로그인 화면을 긁지 않는다. 공식 API가 없는 수집은 하지 않는다 (`data-sources.md` 크롤링 주의).
3. 지금은 은행이 내려 주는 파일 가져오기만 쓴다. 은행별 전용 파서·카드·증권 체결 파일은 기존처럼 샘플이 있을 때 `interop`에 둔다.
4. 나중에 이용기관·인가가 생기면 그때 연다. 그 어댑터는 사용자 동의 뒤에 받은 입출금만 `transactions`에 넣고, `source`는 `csv:`가 아닌 값으로 구분한다. 엔드포인트·파라미터는 그 시점의 공식 문서로 확인하고, 이 ADR에 적지 않는다.

## 결과

- 코드 변경 없음.
- 계획 표는 `docs/tech/data-sources.md`, 파일 경로와의 구분은 `docs/tech/interop.md`.

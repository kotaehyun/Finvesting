# 0017. 부동산 가계대출 비중·유형별 매물 칸

- 상태: 채택
- 날짜: 2026-09-15

## 배경
시·구를 고르면 시도 말잔·증가율만 보이고, 어디가 많은지(비율)·유형별 매물 추이는 없었다. 시·구 가계대출 공식 시계열은 없다. 네이버·직방 매물 호수는 포털이라 크롤링 금지(ADR 0011).

## 결정
- **가계부채 비율**로 보여주는 숫자는 예금은행 가계대출 말잔의 **전국 대비 비중**(서울·경기·인천 / 전국)과 **주택관련 / 가계대출**이다. 가계신용/GDP가 아니다. GDP 비율은 통계코드 확인 전 칸만.
- **어디가 많은지**는 같은 말잔으로 시도 순위 막대. 시·구 순위처럼 보이지 않는다.
- **매물 추이**는 아파트·오피스텔·다가구/빌라·연립·상가·빌딩 여섯 칸 + 빈 그래프. 키 후 국토부 실거래 신고 건수. 포털 호수는 안 긁는다.

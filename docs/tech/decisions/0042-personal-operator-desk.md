# 0042. 프리랜서와 개인사업자는 한 책상

- 상태: 채택
- 날짜: 2026-09-18

## 배경
0038은 `/erp` 카드를 프리랜서·개인사업자·법인 세 장으로 나눴다. 초보·사장님에게는 개인 쪽 카드가 둘이면 종소세·3.3%·매출을 다른 일로 본다. 사용자는 프리랜서와 개인사업자를 묶고 법인만 따로 두라고 했다.

## 결정
- 업무 책상은 두 장. `business`(프리랜서·개인사업자)와 `corporation`(법인사업자).
- `?role=freelancer`는 `business`로 연다. 용역수입·원천 3.3%는 개인 책상 메뉴다. 3.3% 직종 한정(ADR 0039)과 법령 주의(ADR 0040)는 그대로다.
- 법인 책장에는 종소세·간이과세·3.3%를 두지 않는다. 개인 책장에는 법인세·자본조정을 두지 않는다.
- 0038 「인격마다 따로」는 개인 vs 법인으로 읽는다. 카드 세 장은 이 결정으로 수정.

## 결과
`core/work-role.ts` `OPERATOR_ROLES` 두 개. `/erp` 카드 두 장.

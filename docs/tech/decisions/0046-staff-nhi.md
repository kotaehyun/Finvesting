# 0046. 직원등록 다음이 건강보험 자격취득 신고

- 상태: 채택
- 날짜: 2026-09-18

## 배경
직원을 적는 칸과 4대보험 요율 시산이 떨어져 있으면, 채용 다음 할 일(건강보험 직장가입자 신고)이 안 보인다. 보험료를 화면에서 곱하면 공단 부과처럼 보인다.

## 결정
- `/erp?view=staff` 개인·법인 책상. 네 번째 인격 카드 없음.
- 위는 근로기준법 제41조 근로자 명부(시행령 제20조·시행규칙 별지 제16호서식). 30일 미만 일용은 작성하지 않을 수 있음(시행령 제21조).
- 고용일을 적으면 아래 국민건강보험법 시행규칙 별지 제6호서식 직장가입자 자격취득 신고가 이어짐. 기한은 제8조 제2항 취득일부터 14일.
- 1개월 미만 일용은 직장가입자가 아님(제6조 제2항 제1호). 자동 제외하지 않음.
- 자격취득일이 비면 고용일. 보험료·요율을 곱하지 않음. 공단 EDI 전송 아님. 피부양자 제5쪽 칸은 만들지 않음.
- 공식 창구는 국민건강보험공단·건강보험 EDI·4대사회보험 정보연계센터 링크만. 자격취득 Open API는 없음.
- 화면 예시는 명부(홍길동·고용일) → 자격취득 칸 → 시산 CSV → 공식 창구. 주민번호·사업장관리번호·월급은 비움.
- 나중에 EDI 빈 엑셀·공개 API가 오면 `NHI_LATER`만 채움. 지금은 컬럼·엔드포인트를 추측하지 않음.
- 주민등록번호는 비워도 됨. 넣어도 이 기기 CSV만. 서버에 저장하지 않음.
- 시산 CSV는 넣은 칸만. 빈 칸은 0 아님.

## 결과
`core/staff-register.ts`, `/erp?view=staff`. 인건비 화면에서 이어짐.

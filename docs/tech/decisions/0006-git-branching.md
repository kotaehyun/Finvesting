# 0006 — main / dev / 기능 브랜치
- 상태: 채택 (2026-09-02)
- 배경: 혼자 개발하지만 Claude·Cursor·ChatGPT 등 여러 AI 도구가 같은 저장소를 수정하고, 맥북·윈도우 두 기기를 오간다. main에 검증 안 된 변경이 섞이면 어느 상태가 안전한지 알 수 없다.
- 결정: `main`(검증됨) ← `dev`(통합) ← `feat|fix|docs|chore/<이름>`(작업 단위). AI 도구는 기능 브랜치에서만 커밋. 상세 `docs/tech/git-workflow.md`.
- 결과: main은 항상 실행 가능한 상태를 유지. 브랜치 전환·merge 비용은 늘지만 도구 간 충돌과 검증 안 된 변경의 유입을 막는다.

# 0065 — 능동 알림은 홈 확인할 일에 모은다

- 상태: 채택 (2026-11-22)
- 배경: 5단계의 능동 알림에 전달 규칙이 없었다. 푸시·메일은 호스팅·기기 주소가 없다.

## 결정
1. 푸시·메일·워커 발송은 하지 않는다. 홈 「확인할 일」과 챗 `확인할 일` 블록에만 올린다.
2. 올리는 항목은 이미 있는 계산만 쓴다. 미분류 거래, 시세 없는 보유, 이상 지출 플래그(ADR 0062), 보유 집중·코인 경험 규칙(ADR 0063), 반복 패턴(ADR 0064).
3. 새 통계·임계값을 만들지 않는다. 40%·20%·2회는 기존 ADR을 따른다.
4. 결과가 없으면 「지금 확인할 항목이 없습니다」라고만 한다.

## 결과
`packages/core/src/proactive-alerts.ts`. `dashboard.overview.alerts`. 홈·챗.

# 0044. 법인세 서식은 문언 칸과 직역, 뽑기는 빈 칸을 0으로 안 채움

- 상태: 채택
- 날짜: 2026-09-18

## 배경
자본조정을 화면 이름으로 두면 별지 제50호서식의 과목과 섞인다. 비상장 법인 신고는 양도세 칸이 아니다. 파일로 뽑을 때 빈 칸을 0으로 채우면 신고 숫자처럼 보인다.

## 결정
- 법인 `/erp?view=equity`는 법인세법 시행규칙 별지 제50호서식(갑)(을) 문언. 자본조정은 과목. 병은 원문 없이 칸을 만들지 않음.
- 법인 `/erp?view=unlisted`는 별지 제54호서식 주식등변동상황명세서 필요적 기재사항만. 원인코드표를 만들지 않음. 개인 비상장은 소득세법 제105조 예정신고.
- 공식 칸 밑에 직역. 기말은 기초·감소·증가를 다 넣은 뒤에만.
- 시산 CSV는 서식명·근거·직역·주의 뒤 넣은 행만. 빈 칸은 빈 칸. 홈택스 제출·더존 업로드가 아님. 실제 업로드 양식은 빈 템플릿을 받은 뒤(ADR interop).

## 결과
`core/cit-schedules.ts`, `core/form-csv.ts`. 사업 자금·장부 분개 CSV. `/erp` 갑·을·주식변동 화면.

# 0051 — 네이버 뉴스 검색 API는 호출하지 않음
- 상태: 채택 (2026-11-08)
- 배경: NAVER API HUB 검색은 종량제다. 종량제는 요금이 나중에 붙을 수 있다. 키를 넣어 두면 수집기가 붙는 순간 청구가 생긴다.
- 결정: 뉴스 검색 API를 호출하지 않는다. `NAVER_CLIENT_ID`·`NAVER_CLIENT_SECRET`은 두지 않는다. 종목 뉴스는 기존 RSS만 쓴다.
- 결과: 네이버 증권·시세 페이지로 나가는 링크는 이 API가 아니므로 그대로 둔다. 본문은 저장하지 않는다 (ADR 0005).

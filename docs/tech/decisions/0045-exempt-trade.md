# 0045. 면세·확인서·수출입은 조문 칸과 직역

- 상태: 채택
- 날짜: 2026-09-18

## 배경
면세사업자 확인서·사단법인·농업법인·수출입을 부가세 10% 시산과 섞거나, 확인서를 임의 서식 이름으로 두면 2월 신고와 민원 증명이 섞인다.

## 결정
- `/erp?view=exempt` 개인·법인 책상 공통. 네 번째 인격 카드 없음.
- 2월은 소득세법 제78조 사업장현황신고(다음해 2.10). 흔히 확인서라고 부르는 것은 부가가치세면세사업자수입금액증명(국세청민원사무처리규정 별지서식 11호). 화면에서 발급하지 않음.
- 사단법인은 부가가치세법 제26조 제1항 제18호·시행령 제45조. 이름만으로 면세 아님.
- 농업법인은 제26조 제1항 제1호 미가공. 조특법 감면율을 만들지 않음.
- 수출은 제21조 영세율(0%이지 면세 아님). 수입은 제50조 세관 신고·납부. 과세표준 제29조 제2항·납부유예 제50조의2는 칸만. 환율·관세 10%를 곱하지 않음.
- 시산 CSV는 넣은 칸만. 빈 칸은 0 아님. 홈택스 제출·더존 업로드가 아님.

## 결과
`core/exempt-trade.ts`, `/erp?view=exempt`. 부가세 달력에 제78조 행(개인만).

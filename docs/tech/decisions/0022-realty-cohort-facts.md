# 0022. 부동산 평균의 함정은 혼인·출산 코호트

- 상태: 채택
- 날짜: 2026-09-15

## 배경
전국 평균·중위만 보면 시장이 왜곡된다. 인구 최빈은 50대인데, 혼인·출산·신혼 주택은 30대 초반에 몰린다. 떠도는 말 카드에 숫자 칩이 없으면 팩트체크가 문장만 된다.

## 결정
- 연령대 비중은 2025 인구주택총조사(등록센서스). 50대 16.7%가 최빈, 30·40대 합 28.3%를 혼인·출산 중심 구간으로 표시.
- 활동은 혼인·출생 공표(초혼 여 31.6·남 33.9, 30–34세 혼인율·출산율 최고)와 주거실태조사 청년(19–34)·신혼(혼인 7년 이하) PIR·자가점유.
- 생애최초 **햇수(7.9년)** 와 **최근 4년 이내 가구주 연령(46.4세)** 은 기준이 달라 같이 쓰지 않고 라벨을 나눈다.
- 매입 연령대·가구주 연령별 소비는 부동산원·가계동향조사 칸. 등기정보광장·포털은 긁지 않는다.
- 주장 카드에 공식 숫자 `facts`를 붙인다. 유튜브 본문은 저장하지 않는다.

## 결과
`core/realty-cohort.ts`, 주장 `facts`, `/realty` 떠도는 말 칸 위 연령 막대.

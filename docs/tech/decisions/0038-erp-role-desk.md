# 0038. 업무 화면은 인격마다 따로

- 상태: 채택
- 날짜: 2026-09-18

## 배경
`/erp`에 프리랜서·개인사업자·법인 메뉴와 아이콘을 한 사이드에 모아 두면 초보와 사장님이 법인세·종소세·3.3%를 같은 일로 본다. 특화한 실무자가 아니면 아이콘이 많을수록 어렵다.

## 결정
- `/erp`는 인격 고르기만. 카드 두 장(프리랜서·개인사업자 / 법인사업자). 모듈 아이콘 격자 없음. 카드 세 장은 ADR 0042가 수정.
- `/erp?role=business`와 `/erp?role=corporation`은 각각 그 메뉴만. 개인 사장님 화면에 법인세·자본조정을 두지 않음. 법인 화면에 종소세·간이과세를 두지 않음.
- 부가세처럼 둘이 쓰는 화면은 `role` 없이 열면 다시 고른다. 고른 뒤에는 인격 전환 버튼을 숨김.
- 근로자 연말정산은 프로필대장. 업무 사이드에 개인·근로 메뉴를 섞지 않음.

## 결과
`core/work-role.ts` `workPath`·`resolveOperatorRole`. `/erp` 역할 책상.

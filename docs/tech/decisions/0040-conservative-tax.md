# 0040. 세무 화면은 법령 문언만 보수적으로

- 상태: 채택
- 날짜: 2026-09-18

## 배경
3.3%·알바·전문직을 절세처럼 적으면 세무조사에 노출된다. 유튜브 절세 특강은 이 화면에 넣지 않는다.

## 결정
- 조문·시행령에 없는 공제·세율·해석을 만들지 않음.
- 사용종속관계가 애매하면 근로소득(소득세법 제20조, 제129조 제1항 제1호). 사업소득 3%(같은 조 제3호)를 쓰지 않음.
- 화면 숫자는 시산. 신고 대행·절세 자문·세무조사 방어가 아님.
- 아르바이트 3.3% 안내는 법령 주의이지 절세 특약이 아님.

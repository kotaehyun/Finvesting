# 0037. 차대변 장부·연말정산 공제 창·종소세·비상장 2월

- 상태: 채택
- 날짜: 2026-09-18

## 배경
사업 자금·장부가 한 칸이면 차대가 안 보인다. 연말정산 공제는 의료·카드만 있어 기부금·자녀를 넣을 곳이 없다. 비상장 하반기 양도 예정신고(2월)와 종소세(5월)가 법인세·연말정산과 섞인다.

## 결정
- `/erp?view=cash|books` 차변·대변 계정과목 분개. 보통예금 주석은 은행명(ADR 0043). 원장 저장 없음. 가계 CSV 아님.
- `/erp?view=equity` 법인세법 시행규칙 별지 제50호서식(갑)(을). 자본조정은 과목 이름(ADR 0044).
- 프로필 12 연말정산 공제는 창(근로·가족·보험·의료·교육·기부금·주택·카드). 자녀 수·기부금은 입력 칸. 세액공제율을 곱하지 않음.
- `/erp?view=git` 종소세. 소득세법 제70조 5.1~5.31. 세율 구간 미적용. 넣은 산출세액의 10%만 지방세.
- `/erp?view=unlisted` 개인은 소득세법 제105조 예정신고. 법인은 별지 제54호 주식등변동상황명세서(ADR 0044). 세율·평가 없음. 법인세 확정은 3월.

## 결과
`core/biz-journal.ts`, `year-end-deductions.ts`, `gitax.ts`, `unlisted-filing.ts`.

# 0058 — 챗 답은 토큰이 오는 대로 보낸다
- 상태: 채택 (2026-11-12)
- 배경: `LlmProvider.chatStream`은 Ollama에만 있고, `/chat`은 `chat.ask`가 끝날 때까지 기다렸다. 계획의 다음 칸은 스트리밍이다. 대화 저장 테이블은 그 다음이다.
- 결정: `chat.ask`는 그대로 한 번에 답을 돌려준다. `chat.askStream`은 같은 컨텍스트로 델타만 흘린다. 웹 클라이언트는 `httpBatchStreamLink`를 쓴다. 화면은 글자가 붙는 대로 보여주고, 멈추기는 요청을 끊는다. 대화는 저장하지 않는다.
- 결과: 프로바이더에 `chatStream`이 없으면 완성된 답을 한 덩어리로 보낸다.

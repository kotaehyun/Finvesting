# 0025. 부동산 대출 금리는 한은·COFIX 표

- 상태: 채택
- 날짜: 2026-09-15

## 배경
가계대출 말잔만 있으면 이자 부담이 안 보인다. 개별 은행 주담대 상품금리·비교 사이트는 공식 시계열이 아니거나 스크래핑이 된다.

## 결정
- `/realty`에 대출 금리 표를 둔다. 숫자는 한국은행 금융기관 가중평균금리(신규·잔액)와 금통위 기준금리, 은행연합회 COFIX.
- 8월 가중평균은 공표일(2026-09-30) 전이라 넣지 않는다. 가계·주담대·전세·신용은 7월 보도 붙임.
- ECOS `121Y006`·`121Y015`는 항목 목록 **이름 매칭**만. 코드 추측 없음. 매칭되면 스냅샷보다 같은 달·이후만 덮는다.
- 금융상품한눈에·COFIX 원문은 링크. 은행별 금리는 긁지 않는다.

## 결과
`core/realty-rates.ts`, worker `collectEcos` 금리 시계열, `/realty` 표.

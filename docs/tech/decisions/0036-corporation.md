# 0036. 법인사업자는 개인사업자와 다른 인격

- 상태: 채택
- 날짜: 2026-09-18

## 배경
`/erp`의 사업자를 개인만으로 두면 법인 부가세 예정·법인세·대표 급여를 종소세·3.3%와 섞는다.

## 결정
- 역할에 `corporation`(법인사업자)를 둔다. `business` 라벨은 프리랜서·개인사업자(ADR 0042).
- 법인은 간이과세 없음(부가가치세법 제61조). 부가세 10%는 일반/면세만.
- `/erp?view=cit` 법인세 양식. 세율 구간을 곱하지 않음. 넣은 산출세액의 10%만 법인지방소득세(지방세법 제103조의20). 중간예납·확정 달력은 법인세법 제63조·제60조.
- 법인 대표 급여는 근로소득·4대보험. 3.3%가 아님. 종소세·연말정산이 아님.
- 매출·매입·부가세·인건비 칸은 개인·법인이 같은 법령을 쓰되, 화면은 인격마다 따로(ADR 0038). 법인세 칸은 법인만.

## 결과
`core/work-role.ts`, `corp-tax.ts`, `/erp` 법인 메뉴.

# 0052 — 종목 뉴스는 제목의 회사명·긴 티커만
- 상태: 채택 (2026-11-08, 2026-11-11 수정)
- 배경: 제목에 티커가 포함되는지만 보면 `V`가 "Very"에 걸린다. 대소문자를 무시하면 `COST`가 "cost"에 걸린다. 한글을 포함으로만 보면 `카카오`가 "카카오뱅크"에 걸린다. 검색으로 들어온 글도 이 제목 규칙을 다시 통과해야 한다. 수집 호출은 ADR 0057.
- 결정: 영문 티커·영문 회사명은 저장된 대소문자와 단어 경계로 찾는다. 3글자 이하 티커와 숫자 종목코드는 제목에서 찾지 않는다. 한글 회사명은 바로 앞이 한글·숫자이면 제외하고, 바로 뒤의 한글은 조사(`HANGUL_NAME_PARTICLES`)일 때만 허용한다. RSS와 네이버 검색을 넣을 때 같은 함수로 `market_news.symbols`를 채운다. 이미 저장된 `symbols`는 다시 쓰지 않는다. 조회는 그 배열만으로 통과시키지 않고 제목 규칙으로 다시 거른다. 관심 목록·시가총액 보드·`watchNews`는 최신 N건을 통째로 보지 않는다. 종목마다 `symbols`에 코드가 있거나, 4글자 이상 티커·2글자 이상 회사명이 제목에 있으면 전체 기간에서 후보 200건을 가져와 같은 함수로 거른다. 시가총액 보드는 오피니언 소스를 빼는 기존 조건을 유지한다. 본문은 저장하지 않는다 (ADR 0005).
- 결과: 관심 종목·시가총액 뉴스와 수집이 같은 제목 규칙과 같은 후보 조회를 쓴다.

# 0052 — 종목 뉴스는 제목의 회사명·긴 티커만
- 상태: 채택 (2026-11-08)
- 배경: 제목에 티커가 포함되는지만 보면 `V`가 "Very"에 걸린다. 네이버 뉴스 검색 API는 쓰지 않는다 (ADR 0051).
- 결정: `symbols` 배열은 종목 코드가 정확히 같을 때만. 제목의 영문 티커는 단어 경계로 찾고, 3글자 이하·숫자 종목코드는 제목에서 찾지 않는다. 한글 이름은 포함, 영문 이름은 단어 경계. RSS를 넣을 때 같은 함수로 `market_news.symbols`를 채운다. 본문은 저장하지 않는다 (ADR 0005).
- 결과: 관심 종목·시가총액 뉴스와 수집이 같은 규칙을 쓴다. 이미 저장된 글의 `symbols`는 다음 수집에서 갱신되지 않고, 조회 때 제목으로 다시 맞춘다.

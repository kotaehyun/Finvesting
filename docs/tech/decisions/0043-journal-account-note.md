# 0043. 분개는 차변·대변 계정과목과 예금 주석

- 상태: 채택
- 날짜: 2026-09-18

## 배경
사업 자금 전표를 계정 한 칸·금액 차대만으로 두면 복식부기 분개가 아니다. 보통예금은 계정과목이고, 어느 은행인지는 보조 주석이다.

## 결정
- `/erp?view=cash|books`는 일자, 차변 계정·주석·금액, 대변 계정·주석·금액, 적요.
- 계정과목은 `보통예금`이다. `사업보통예금`처럼 만들지 않는다. 가계와 사업의 구분은 책상이다.
- 보통예금·당좌예금·정기예금·외화예금이면 밑 주석에 은행명을 쓴다. 은행 이름을 목록으로 만들지 않는다. 금액이 있는데 주석이 없으면 안내만.
- 원장 저장 없음. 0037 전표 칸을 이 양식으로 수정.

## 결과
`core/biz-journal.ts` 차변·대변 계정 필드. `/erp` 분개 표.

# 0010 — 투자성향 설문은 내부 경험 규칙

- 상태: 채택
- 날짜: 2026-09-14

## 배경
프로필에 위험 성향 3단(보수·중립·공격)만 있고, 보유와 비교한 조언 화면이 없었다. 증권사 적합성 설문을 그대로 옮기면 저작·규제 문구가 섞인다.

## 결정
- `/profile` 10 투자성향에 기간·경험·손실감수·목적 4문항(각 0–3점, 합 0–12)만 둔다.
- 0–4 보수, 5–8 중립, 9–12 공격. 완료 저장 시 `risk_tolerance`를 맞춘다.
- 조언은 `core/invest-style`이 보유 비중·비상금·집중·해외통화로 문장을 만들고, AI는 그 문장만 다시 설명한다. 종목·상품 추천 금지.
- 금융투자협회·증권사 적합성 평가가 아님을 UI·프롬프트에 밝힌다.

## 결과
`financial_profiles.invest_style` jsonb. `profile.investAdvice` / `upsertInvestStyle` / `investRecommend`.

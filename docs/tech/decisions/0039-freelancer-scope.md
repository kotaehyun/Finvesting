# 0039. 프리랜서 3.3%는 직종을 엄격히 본다

- 상태: 채택
- 날짜: 2026-09-18

## 배경
알바·위장 프리랜서(소위 사짜)를 3.3%로 넣는 사람이 많다. 매장 근무와 인플루언서를 같은 알바로 본다.

## 결정
- `/erp` 프리랜서 원천 시산은 **연예인·모델·프리랜서 개발자·인플루언서·전문직**(의사·변호사·노무사·세무사·변리사 등)만 연다. 개원·사무소는 개인사업자.
- 아르바이트생을 3.3%로 억지로 돌리지 않음. 법령 주의 문구는 소득세법 제20조, 제127조·제129조 제1항 제1호, 같은 조 제3호, 근로기준법 제2조 제1항 제1호.
- 매장 알바·상주 개발·위장 3.3%(사짜)는 근로소득. 조건을 다 켜기 전에는 3.3%를 곱하지 않음.
- 직종 한정은 **이 화면 안내**. 소득세법이 이 직종만 허용한다고 쓰지 않음. 법령 주의는 법률자문·절세 자문이 아님. 해석은 ADR 0040.

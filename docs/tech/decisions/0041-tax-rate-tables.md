# 0041. 양도·증여·보유 세율표는 법령 문언을 보여 준다

- 상태: 채택
- 날짜: 2026-09-18

## 배경
초보는 과세표준·누진세율 용어부터 막힌다. 0032는 세율을 곱하지 말라고 했다. 표를 숨기면 더 모른다. 특례를 화면에 해석하면 ADR 0040에 어긋난다.

## 결정
- 소득세법 제55조(종소·양도 기본), 제104조 단기·주식, 상속세 및 증여세법 제26조·제56조, 제53조 공제 한도, 지방세법 제111조 주택 재산세, 종합부동산세법 제9조 주택분을 **조문 표로 보여 줌**.
- 넣은 과세표준으로 산출세액 시산만. 공시가격·매매가에 세율을 곱하지 않음. 1세대1주택 비과세·중과·합산배제·조례 가감은 자동 적용하지 않음.
- 자세한 특이사항은 담당 세무사·공인회계사·전문가 상담이 먼저. 국세청 126·홈택스·관할 세무서.
- 0032 「세율 없음」은 원장에 결정세액을 쓰지 말라는 뜻. 법령 세율표 안내는 예외.

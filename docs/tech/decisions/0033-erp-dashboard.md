# 0033. ERP 업무홈은 자산 홈과 분리, 위하고는 시각만

- 상태: 채택
- 날짜: 2026-09-18

## 배경
프로필 12 세무·회계는 대장 안 칸이었다. 위하고처럼 업무 모듈 홈이 필요하고, 자산 홈(`/`)과 섞이면 안 된다. 더존 API·업로드 양식은 없다.

## 결정
- `/erp` 별도 대시보드. 남색+시안 업무홈, 모듈 타일, 현황 위젯. 더존 제품이 아님.
- 숫자는 기존 통장·급여 스냅샷·체결·세무 미리보기만. 매출·매입·부가세·세율을 만들지 않음.
- 세무 상세는 `/erp?view=tax`와 프로필 12가 같은 `TaxBooksPanel`. **0034에서 철회: 근로 세무는 대장만.**

# docs — 프로젝트 문서 (SSOT)

이 폴더는 사람과 AI 도구 모두가 참조하는 **단일 진실 원천**이다. 코드와 문서가 어긋나면 문서를 고치거나 코드를 고쳐서 반드시 일치시킨다.

## AI 도구 작업 규칙

1. 작업 시작 전 `00-overview`, `10-architecture`, `70-progress`를 읽는다. 스키마를 건드리면 `20-data-model`, 수집기를 건드리면 `30-data-sources`, AI를 건드리면 `40-ai`도 읽는다.
2. 문서에 없는 것은 **추측하지 말고** 코드를 확인하거나 사용자에게 묻는다.
3. 작업 후 반드시:
   - `70-progress/README.md`에 날짜·작업 내용·다음 할 일을 추가
   - 구조/스키마/소스/AI 변경 시 해당 폴더 문서 업데이트
   - 중요한 기술 선택은 `60-decisions/`에 ADR 한 장 추가 (`NNNN-제목.md`)
4. 문서는 한국어, 코드 식별자는 영어 그대로.

## 폴더

| 폴더 | 내용 | 갱신 시점 |
|---|---|---|
| `00-overview/` | 제품 정의, 핵심 사용자, 범위 | 제품 방향이 바뀔 때 |
| `10-architecture/` | 모노레포 구조, 데이터 흐름, 스택 | 앱/패키지 추가·구조 변경 시 |
| `20-data-model/` | 테이블·컬럼 의미, 관계 | 스키마 변경 시 (마이그레이션과 같이) |
| `30-data-sources/` | 수집 소스, 스케줄, 어댑터 | 소스 추가·변경 시 |
| `40-ai/` | 챗봇, 프로바이더, 프롬프트, RAG | AI 관련 변경 시 |
| `50-setup/` | 맥/윈도우 환경, 명령어 | 설정 방법이 바뀔 때 |
| `60-decisions/` | ADR | 기술 결정 시 |
| `70-progress/` | 진행 로그 | **매 작업 세션** |
| `80-roadmap/` | MVP 단계, 백로그 | 우선순위 변경 시 |

## 발견한 문제 (모두 대상 커밋 기준)

### 1. [P1] 대출 과거 값을 생성하여 공식 통계처럼 반환
- 위치: `packages/api/src/routers/market.ts:615`, 특히 643–653.
- DB 실패 또는 데이터 0건이면 고정 17개 지역값을 반환하고, 과거 대출은 현재값×0.96, 과거 주담대는 ×0.95로 생성한다. 이 값으로 순위·비중·전년비·추이 그래프가 계산되며 반환에 폴백 상태 표시가 없다.
- 고정 커밋의 실제 tRPC caller + 실패하는 DB mock으로 서울 2025-07=369792, 2026-07=385200, 전년비 4.1667%를 확인. 지역 합계 1148100은 전국값 1128000과도 불일치한다.
- 수정: 실제 캐시가 있으면 출처·수집일·오래됨 상태와 함께 반환. 실측 과거 자료가 없으면 빈 추이를 표시하고 수식으로 과거 통계를 만들지 않는다.

### 2. [P1] 미수집/DB 장애를 고정 펀더멘털로 숨김

- DB mock 재현: 5개 반환, 첫 instrumentId=fallback-aapl, source=yahoo.
- 수정: API 응답에 ok/empty/unavailable/stale 등 명확한 상태를 두고, 데모 데이터는 명시적으로 선택하는 별도 모드로 격리. 실제 캐시와 샘플을 혼합하지 않는다.

### 3. [P1] 뉴스 오류 폴백이 기사 출처와 필터 계약을 깨뜨림
- 위치: `packages/api/src/routers/market.ts:175–197`, `packages/core/src/realty-news.ts:13`.
- 오류 시 고정 제목·발행 시각·언론사와 기관 홈페이지/RSS 주소를 뉴스 기사처럼 반환한다. 예컨대 연합뉴스 항목의 링크는 해당 기사 대신 법원경매 홈페이지다. 개별 기사 원문을 확인할 수 없다.
- lang/category/publisher/limit를 무시한다. DB mock으로 lang=en, category=crypto, limit=1 요청에 한국어 부동산 6건 반환을 확인했다. 모든 source도 한경 RSS로 일괄 부여된다.
- 수정: 검증된 기사 메타데이터 캐시만 사용하고 필터·개수 계약 유지. 기사 없이 기관 링크만 있으면 뉴스가 아닌 참고 사이트로 표시한다. 외부 기사 존재 여부 자체를 이번 검토에서 검증한 것은 아니다.

### 4. [P2] 52주 가격 게이지가 실제 가격과 무관하게 50%

- current 인자로 현재가가 아니라 (low+high)/2를 전달한다. high>low인 모든 종목이 50%다.
- 실제 fiftyTwoWeekPosition에 화면과 동일 인자를 넣어 [100,200], [10,1000] 모두 50 확인.
- 수정: 해당 종목의 현재/최근 종가와 기준시각을 가져와 계산. 가격이 없으면 범위 수치만 보여주고 위치 게이지는 숨긴다. 함수 단위 테스트 외에 실제 화면에 전달하는 값도 검증한다.

# review — 코드 리뷰 기록

리뷰할 때마다 파일 하나: `YYYY-MM-DD-대상.md` (예: `2026-09-10-worker-rss.md`)
AI 도구가 리뷰하면 반드시 여기에 남기고, 반영 여부를 표시한다.

## 형식
```
# 대상 (파일/패키지/기능)
- 날짜:
- 리뷰어: 사람 / Claude / Cursor / ...
- 범위: 어떤 파일·커밋

## 발견한 문제
| # | 심각도(높음/중간/낮음) | 위치 | 내용 | 반영 |
|---|---|---|---|---|

## 개선 제안
- ...

## 잘된 점
- ...
```

## 개선 제안
- `latestNews`는 컬럼을 명시하고, 챗 거시지표는 **코드별 최신 1건**(또는 `DISTINCT ON (code)`).
- 챗 컨텍스트에 대시보드와 같은 순자산·현금흐름을 넣고, 아직 없으면 시스템 프롬프트에서 “보유 데이터 없음”을 분명히 할 것.
- 시세 upsert `set`에 open/high/low/volume을 포함.
- Next `.env` 로딩을 dotenv로 맞추거나 인라인 주석을 자르기. `.env.example` 주석을 값 옆이 아니라 윗줄로.
- DART 타깃은 `stock`·`corp`가 있을 때만 호출. EDGAR는 `end`/`filed` 최신 facts만, `SEC_USER_AGENT` 미설정 시 skip.
- `quotes` 유니크에 `source`를 넣을지는 KIS 붙이기 전에 ADR로 결정.

## 잘된 점
- 패키지 의존 방향(core 순수, web/mobile의 DB 직접 접근 없음, worker는 db)은 유지됨. 뉴스 본문 미저장.
- 소스별 try/catch 격리, RSS per-feed 통계, Yahoo v3 + 429 백오프, 시세일 `regularMarketTime` 미국 동부 날짜 — 첫 실행에서 실제로 통했음.
- 대시보드 월 말일 `new Date(y, m, 0)` (m은 1-based)는 올바름. 기본 월은 KST.
- `/chat` IME `isComposing` 가드, 라이트/다크 팔레트, 답변 마크다운(react-markdown은 기본으로 raw HTML 비활성).
- `ensureInstrument`의 insert 레이스 재조회, Upbit 마켓별 실패 격리.
- `core/portfolio` 환율 가중평균·원화 손익 + 테스트 5개(이번 세션에서 9/9 통과 확인).
- worker 루트 `.env` 경로 4단계(`src/lib` → 루트)는 문서·로그와 일치.
